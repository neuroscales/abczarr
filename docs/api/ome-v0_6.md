# OME-Zarr metadata — NGFF 0.6

The released 0.6 model.

## Changes from NGFF 0.6rc0

The metadata model is unchanged from the release candidate. The published
schemas differ only in wording and spelling: the version enum now also
accepts the `"0.6rc0"` string, two transform descriptions read "Indices"
rather than "Names" of the input and output axes, one cross-file reference
in `coordinate_systems.schema` is spelled as a full URL, and a typo in an
`image.schema` description is fixed. None of these changes the shape of any
document, so a `0.6rc0` object and a `0.6` object carry the same fields.
