# Type aliases

These aliases name the shapes that recur throughout the metadata API. A
constructor signature that accepts JSON, or an array shape, is written in
terms of one of these names rather than its full expansion.

These aliases are documented here only to explain the names that appear
in constructor signatures and attribute types. They are internal to the
library and are not part of its public interface. Application code should
not import them or depend on their definitions, which may change without
notice.
